## Problem

Typed CST wrappers and typed AST extraction must project from `AdzeDocument`,
not from a separate tree or independent parse product. Without a clear
projection contract, typed wrappers could copy tree data, typed AST extraction
could silently discard provenance, and the two could drift from each other and
from the native document.

## Behavior

### Typed CST is generated over AdzeDocument

Typed CST wrappers are generated by tablegen and reference document node IDs.
They do not own a second tree or copy source text.

```rust
pub struct BinaryExpr<'a> {
    doc: &'a AdzeDocument,
    node_id: NodeId,
}
```

Accessors resolve fields through native edge metadata:

```rust
impl<'a> BinaryExpr<'a> {
    pub fn left(&self) -> Result<Expr<'a>> { ... }
    pub fn operator(&self) -> Result<&'a str> { ... }
    pub fn right(&self) -> Result<Expr<'a>> { ... }
    pub fn span(&self) -> ByteRange { ... }
    pub fn text(&self) -> &'a str { ... }
}
```

### Typed CST wrappers do not own a second tree

Typed CST types borrow from `AdzeDocument`. They hold a document reference and
a node ID. They do not clone nodes, edges, or source text.

### Typed AST lowering is a semantic projection

Typed AST extraction lowers document nodes into semantic Rust types. This is a
projection, not a second parse. The typed AST implements `Extract<T>` and reads
from document node data.

```rust
let doc = grammar::parse_document("1 + 2")?;
let ast: Expr = doc.ast()?;
```

### parse() is sugar over document AST projection

```rust
// These produce the same typed value:
let ast: Expr = grammar::parse("1 + 2")?;
let doc = grammar::parse_document("1 + 2")?;
let ast2: Expr = doc.ast()?;
```

The `parse()` function is stable ergonomic sugar. `doc.ast()` is the
experimental projection entry point.

### Provenance is sidecar-based

AST provenance is recorded as a sidecar structure attached to the extraction
result, not as per-AST-node metadata inside `AdzeDocument`.

```rust
pub struct AstWithProvenance<T> {
    pub value: T,
    pub provenance: Provenance,
}
```

Provenance records which document node was the extraction root and which
projection path was used.

### Default AST extraction is strict

By default, `doc.ast()` rejects documents with unrecovered errors. Users who
want best-effort AST extraction from partial parses must opt in explicitly.

### Typed CST is lenient where the document has data

Typed CST wrappers expose whatever the document contains, including error nodes
and missing children. This is source-preserving syntax access, not semantic
validation.

## Non-Goals

- Per-AST-node provenance (document-level provenance first).
- Typed CST visitor or rewriter API.
- Typed CST JSON schema.
- Broad typed CST / generic CST parity matrix (incremental proof).

## Required Evidence

- Typed CST wrappers resolve fields through `AdzeEdge` metadata.
- Typed CST wrappers do not clone source text.
- `parse::<T>()` and `doc.ast::<T>()` produce identical results.
- Provenance records the extraction root node.
- Default `doc.ast()` rejects documents with unrecovered errors.

## Acceptance Examples

### Typed CST field access

```rust
let doc = grammar::parse_document("1 + 2")?;
let syntax: syntax::SourceFile = doc.syntax()?;
let expr = syntax.root().as_binary_expr()?;
assert_eq!(expr.left()?.text(), "1");
assert_eq!(expr.operator()?, "+");
assert_eq!(expr.right()?.text(), "2");
```

### parse() == doc.ast()

```rust
let ast1: Expr = grammar::parse("1 + 2")?;
let doc = grammar::parse_document("1 + 2")?;
let ast2: Expr = doc.ast()?;
assert_eq!(format!("{ast1:?}"), format!("{ast2:?}"));
```

### Error document rejects default AST

```rust
let doc = grammar::parse_document("1 + ")?;
assert!(doc.ast::<Expr>().is_err());
```

## Metrics And Promotion Rule

Typed AST: already stable. Promotion to stable required proof that `parse()`
and `doc.ast()` agree for all supported grammars.

Typed CST: experimental. Promotion to stabilizing requires:
- Generated wrappers exist for at least two grammar families.
- Wrapper field access agrees with generic CST field access.
- No typed CST wrapper clones source text.
