# 0.9 Contract Convergence Closeout

Milestone: 0.9.0
Date:
Owner: Adze maintainers
Status: draft

## What Shipped

- API foundation proposal and eight behavior specs defining the AdzeDocument
  architecture and projection contracts.
- Source-of-truth scaffold: proposals, specs, ADRs, plans, goal manifests,
  handoffs, and artifact templates.
- Document artifact ledger (`policy/doc-artifacts.toml`) enabling automated
  artifact validation.
- Product proof map (`docs/status/PRODUCT_PROOF_MAP.md`) mapping every product
  claim to its spec and proof command.
- Agent implementation contract (`docs/agents/IMPLEMENTATION_CONTRACT.md`)
  defining the rules for autonomous agents.
- CI economics docs reconciled with label vocabulary and lane metadata.
- Package boundary audit classifying every workspace package.
- CI economics verifier enabling lane whitelist checks.
- Four proof-slice PRs landing diagnostics, alias filtering, node-types
  metadata, and EOF recovery canaries.
- Two package-boundary collapse PRs retiring zero-dependency facade crates.

- Typed CST API is not stable.

## Lessons Learned

- Parallel Codex attempts at the same task produce redundant PRs. Close
  superseded attempts early.
- Spec writing before implementation prevents API sprawl.
- Document artifact ledgers enable automated consistency checks.
- The source-of-truth rail (proposal -> spec -> ADR -> plan -> active.toml ->
  PR -> proof -> receipt -> closeout) is the right shape for agent-driven
  development.
